
# ONG Esperança Viva

Projeto desenvolvido para a disciplina — Entregas I a IV.

## 🔎 Sobre
Site institucional de uma ONG fictícia dedicada à educação, inclusão social e voluntariado.

## 🧩 Estrutura do projeto


## ✅ Funcionalidades entregues
- Design System (CSS variables, tipografia, espaçamento)
- Grid 12 colunas, Flexbox, 5 breakpoints
- Menu com dropdown e menu hambúrguer (mobile)
- Componentes: cards, botões com estados, formulários com validação, modal, toasts, badges
- SPA simples (carregamento parcial com fetch)
- Validação de formulário com mensagens inline e armazenamento em LocalStorage
- Acessibilidade: skip-link, roles, aria-*, navegação por teclado, modo escuro e alto contraste
- Versão final pronta para deploy (GitHub Pages)
